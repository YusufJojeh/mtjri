## Notable capability anomalies discovered during inventory

- `email-templates.*` routes are active and mutable but publicly exposed in `routes/web.php`.
- `settings.webhooks.*` backend routes are commented out in `routes/settings.php`, while webhook UI logic still calls those route names.
- Backend routes render `ai-templates/index`, `webhooks/index`, `payment-gateways/index` but matching page files are absent under `resources/js/pages`.
